# Function and Class-Level Documentation

This is a navigation catalog of the backend's important types and callable
entry points. It is not a generated API reference for every private helper.
Names below are grouped by module; route handlers are listed in
[02. API Endpoint Documentation](./02.%20API%20ENDPOINT%20DOCUMENTATION.md).

## Application and configuration

| Module | Key symbols | Responsibility |
|---|---|---|
| [`app/main.py`](../../app/main.py) | `app`, `lifespan()`, root/app/static handlers | Builds ASGI app, initializes shared pool, registers routers and static files |
| [`app/_server.py`](../../app/_server.py) | `__main__` launcher | Starts Uvicorn using configured host/port/environment/worker count |
| [`app/config.py`](../../app/config.py) | `FREEZE_RETRIEVAL`, `CREDIT_SYSTEM_ENABLED`, `REQUEST_TIMEOUT`, model IDs, size limits | Loads dotenv values, configures logging and all runtime constants |
| [`app/clients/pool.py`](../../app/clients/pool.py) | `pool`, `init()`, `close()`, `assert_ready()`, cache/rate/token/user helpers | Owns database and HTTP clients, cache, readiness, JWT helper implementations |
| [`app/clients/groq.py`](../../app/clients/groq.py) | `groq_chat()`, `create_embedding()`, `create_embeddings_batch()`, `truncate_messages()` | Groq completion requests, key cycling, prompt truncation, BGE embeddings |

| [`app/core/exceptions.py`](../../app/core/exceptions.py) | `LLMError`, `EmbeddingError`, `VectorSearchError`, `GraphRetrievalError`, `PlanError` | Typed internal errors consumed by routes/helpers |

## Planner, retrieval, generation, and documents

| Module | Important functions | Role |
|---|---|---|
| [`app/core/planner.py`](../../app/core/planner.py) | `_parse_planner_response()`, `_fallback_plan_data()`, `plan_query()`, `read_primary_source_passages()`, `check_requirements_covered()` | Turns query/context into a validated plan; optional primary-PDF extraction and depth self-check |
| [`app/core/retrieval.py`](../../app/core/retrieval.py) | `paper_relevance_score()`, `vector_search()`, `hybrid_search()`, `reciprocal_rank_fusion()`, `mmr_rerank()`, `merge_adjacent_chunks()`, `retrieve_arxiv_context()`, `run_vector_pipeline()`, `build_chronological_flow()` | Vector retrieval helpers, filtering/ranking, ArXiv API lookup and evidence formatting |
| [`app/core/graph.py`](../../app/core/graph.py) | Graph search and context helpers | Neo4j database operations; returns empty results when retrieval is frozen |
| [`app/core/generation.py`](../../app/core/generation.py) | `grounded_prompt()`, `compare_prompt()`, `survey_prompt()`, `timeline_prompt()`, `conceptual_prompt()`, `clean_and_resolve_links()`, `verify_answer()`, `apply_verification()` | Prompt generation, citation/link cleanup, answer verification |
| [`app/core/document.py`](../../app/core/document.py) | `extract_paper_urls()`, `parse_pdf_from_url()`, `get_or_parse_pdf()`, `chunk_document_text()`, `get_relevant_pdf_chunks()` | Remote/local PDF text extraction, chunking, caching, semantic relevance |

`grounded_prompt()` currently takes `depth`, `requirements`, and
`primary_passages`. The research route passes all three for high-depth named
paper questions. That call signature was covered by a regression test after a
runtime argument mismatch was fixed.

## Utilities

| Module | Main responsibility |
|---|---|
| [`app/utils/auth.py`](../../app/utils/auth.py) | Mongo-backed user authentication/dependency helpers |
| [`app/utils/credits.py`](../../app/utils/credits.py) | Feature gates, credit checks/consumption, rate limiter wrapper; routes use this module |
| [`app/utils/email.py`](../../app/utils/email.py) | Verification/reset email delivery path and configuration fallback |
| [`app/utils/conversation.py`](../../app/utils/conversation.py) | Conversation context extraction/formatting for planner/chat |
| [`app/utils/misc.py`](../../app/utils/misc.py) | Link cleanup and dataset/repository aggregation helpers |

Some cache, user-context, rate, token, and plan helpers also exist in
`app/clients/pool.py`; the credit utilities duplicate a subset of those
responsibilities. This is a maintenance risk because edits must keep the
implementations consistent.

`app/embeddingService/embeddings.py` is present in the repository but appears
to be legacy/unused from the inspected main-app call paths. Its import path
references `app._server.EmbeddingError`; direct runtime use has not been
verified.

## Function-map limits

Test, evaluation, frontend-validation, ingestion, and development scripts are
not production request handlers. The files are inventoried in
[12. TESTING AND DEPLOYMENT](./12.%20TESTING%20AND%20DEPLOYMENT.md), but not
every local variable/private helper is reproduced here. For exact current
signatures, the source files remain authoritative.
