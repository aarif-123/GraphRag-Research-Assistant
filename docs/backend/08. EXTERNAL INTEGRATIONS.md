# External Integrations

## Academic research sources

| Source | Connector/use | Data role and caveats |
|---|---|---|
| arXiv | `app/core/retrieval.py` XML feed | Search and retrieve metadata/abstracts, authors, categories, IDs and PDF links; XML failure returns no papers |
| Semantic Scholar | `app/sources/semantic_scholar.py` | Paper search/enrichment and citation/TLDR metadata when configured/available |
| CORE | `app/sources/core.py` | Search/enrichment; provider credentials/limits can restrict availability |
| OpenAlex | `app/sources/openalex.py` | Metadata lookup/enrichment and normalization |
| Papers With Code | `app/sources/papers_with_code.py` | Code/dataset discovery metadata; also queries Hugging Face APIs for resources |

These are API integrations, not a local corpus by themselves. Provider call
coverage varies by route, and empty connector output does not distinguish
“no match” from every failure mode without log inspection.

## Dataset and repository sources

| Source | Typical use |
|---|---|
| Hugging Face | Dataset/model metadata and repository discovery |
| Kaggle | Dataset search/enrichment when credentials and triggering metadata are available |
| Papers With Code | Links research papers to code and datasets |
| GitHub links parsed from paper comments/metadata | Repository URLs included when discovered in provider response |

The standard research path runs dataset/repository aggregation after paper
retrieval. Kaggle enrichment is attempted only when a dataset list already
exists. Therefore an empty Sources/Datasets UI state can mean the API did not
return a dataset candidate; it does not imply paper retrieval failed.

Datasets extracted or linked from a retrieved paper retain a reference to that
paper in the Sources panel. Additional Kaggle and Hugging Face results are
searched using the user's query and concrete dataset names found in the papers;
catalog candidates must match at least two meaningful query terms (or the
single meaningful term in a one-term query) across their names, tags, or
descriptions. Cards label these as catalog search matches rather than implying
that a paper used them.

## Wikipedia

Wikipedia is an alternate direct answer route selected by request mode/prefix
and is also available to chat paths. It is not treated as an academic
peer-reviewed source. Standard research prompts may include a Wikipedia
connector only in explicit Wikipedia mode rather than silently mixing it
into the main academic evidence list.

## Provider call behavior

- Most connector methods are async HTTP clients or are awaited from route
  fan-out.
- Provider-specific response normalization is implemented in the connector.
- Some source helpers catch exceptions, log a warning, and return `[]` or
  `None`. Other failures are surfaced as typed errors and can become a 502.
- Rate limit, API key, and service availability differ by provider; the
  repository does not prove current quotas or external account configuration.
- External URLs and abstract metadata are inputs to model prompts; citation
  cleanup links only to URLs already present in the retrieved context.

## Credentials and deployment boundaries

Credentials should be supplied through environment variables and deployment
secret stores. The repository includes an offline ingestion utility with
hard-coded remote connection configuration; its credential value is
intentionally not reproduced here. Treat any real credential embedded in
source as exposed: remove it from source/history, rotate it with the provider,
and load the replacement through environment configuration before using that
utility.

Relevant environment variables include `S2_API_KEY`, `CORE_API_KEY`,
`OPENALEX_API_KEY` (if configured in the connector),
`KAGGLE_USERNAME`, `KAGGLE_KEY`, and `HF_TOKEN`. Exact names and optionality
should be confirmed in each connector/config module before deployment.

## Independent services and non-integrations

- `knowledge_graph.api:app` can be launched as an independent Neo4j API and
  is not included in the main FastAPI app.
- No message broker or general tool orchestration platform is visible.
